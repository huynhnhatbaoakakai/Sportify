Bài 1 · Web hoạt động như thế nào?

Ví dụ xuyên suốt: bạn mở trang Quản lý sân của Sportify. Đọc sơ đồ từ giữa ra các nhánh, rồi xem luồng ở dưới.

Chưa cần học tên class. Trước hết hãy phân biệt ba vai trò. Với luồng Servlet/JSP đang học, browser không tự truy vấn PostgreSQL; server lấy dữ liệu và tạo HTML. Kết quả database → server không phải HTTP response gửi thẳng tới browser.
Đây là sơ đồ khái niệm để học, không phải bằng chứng ứng dụng đã chạy thành công.
