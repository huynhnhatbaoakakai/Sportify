# Sportify Project Instructions

## Project overview

Sportify là đồ án cuối kỳ môn Web Programming.

Công nghệ:
- Java JSP/Servlet
- Maven
- Apache Tomcat 11
- PostgreSQL sẽ được kết nối sau
- HTML, CSS và JavaScript thuần

Các môn thể thao:
- Gym
- Bóng rổ
- Bơi
- Pickleball

Các dịch vụ:
- Thuê sân/phòng tập
- Thuê quần áo và phụ kiện
- Thuê gear thể thao
- Thuê PT

Các role:
- Khách hàng
- Chủ sân
- Chủ cửa hàng
- PT
- Admin

## Current development phase

Hiện tại giáo viên yêu cầu hoàn thành giao diện trước.
Chưa triển khai database, DAO hoặc chức năng đăng nhập thật.

## Coding rules

- Không thay đổi giao diện cũ nếu không được yêu cầu.
- Không sửa index.jsp, login.jsp, register.jsp và chat.jsp khi làm owner dashboard.
- Chỉ sửa những file liên quan trực tiếp đến nhiệm vụ.
- JSP phải dùng UTF-8.
- Đường dẫn asset phải dùng request.getContextPath().
- CSS và JavaScript phải nằm trong thư mục assets.
- Không dùng framework frontend.
- Không thêm dependency nếu chưa được yêu cầu.
- Không sửa hoặc commit thư mục target.
- Không tự commit hoặc push Git.
- Trước khi sửa phải đọc code hiện tại.
- Sau khi sửa phải báo những file đã thay đổi.
